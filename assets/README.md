# Images for the site

Drop your real images into this `assets/` folder, then in the HTML replace the colored
placeholder blocks (`<div class="ph ...">Label</div>`) with an image tag, e.g.:

```html
<img src="assets/mathflux.png" alt="MathFlux gameplay screen">
```

## Creative page (creative.html)

Add as many images as you like per category (Generative Art, Photography, Digital Painting,
Fine Art, Turkey Chopper, Art/Crafts). Duplicate a `.tile` block for each image.

## Tips
- Use web-friendly sizes (long edge ~1600px, JPG for photos, PNG for UI screens).
- Keep filenames lowercase with hyphens, no spaces.
- After adding images, delete the yellow `.imgnote` banners in work.html and creative.html.
